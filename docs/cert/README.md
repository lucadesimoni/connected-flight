> **DRAFT** for review with the design organisation (DOA). Items in
> ⟨angle brackets⟩ are decisions or data of the DOA / applicant. Not an
> approved document.

| Document | Purpose |
|---|---|
| [PSAC](PSAC.md) | Plan for Software Aspects of Certification: system, software level, life cycle, compliance approach (agreed with the authority) |
| [SDP](SDP.md) | Software Development Plan: standards, environment, how requirements, design and code are produced |
| [SVP](SVP.md) | Software Verification Plan: reviews, tests, robustness, trace matrix, independence |
| [SCMP](SCMP.md) | Software Configuration Management Plan: identification, baselines, change control, SCI, archive |
| [SQAP](SQAP.md) | Software Quality Assurance Plan: audits, conformity review, records |
| [FHA](FHA.md) | Functional Hazard Assessment: failure conditions, classification, DAL derivation |

Order of use: FHA → PSAC (with the authority) → SDP / SVP / SCMP / SQAP →
life-cycle data (requirements in `docs/04`, trace matrix and SCI from CI)
→ Software Accomplishment Summary (SAS) at the end, not yet drafted.
